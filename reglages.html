Réglages

Apparence et stockage propres à cet appareil ; clés API partagées si GitHub est activé

Avant de créer ou choisir un profil sur cet appareil : choisis d'abord où seront stockées les données ci-dessous (« Local » = uniquement cet appareil, « GitHub » = partagé avec tes autres appareils). Enregistre pour continuer.

Apparence

Une palette de couleurs pour toute l'application, propre à cet appareil. S'applique tout de suite.

Stockage des données

« Local » garde tout dans ce navigateur, pratique pour essayer l'appli. « GitHub » écrit dans le repo (chaque ajout = un commit) et rend les données accessibles depuis n'importe quel appareil.

Le token reste uniquement dans ce navigateur. Il n'est jamais écrit dans le repo.

Clés API (auto-complétion)

Gratuites à créer sur le site de chaque service. Sans clé, l'ajout reste possible mais à la main. Communes à tous les appareils si le stockage est réglé sur GitHub ci-dessus ; sinon gardées dans ce navigateur.

Livres/BD (Open Library) et Jeux de société (BoardGameGeek) ne demandent pas de clé.

Exemples de démonstration

Ajoute 5 exemples dans chaque catégorie du profil actif, pour voir l'appli remplie.

Zone dangereuse

Supprime tous les profils et toutes leurs données (collections, notes, activité, top de la semaine) sur ce stockage. Les clés API restent en place. Irréversible.
